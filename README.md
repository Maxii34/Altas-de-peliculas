# 🎬 Altas de Películas

Una aplicación web simple y elegante para **dar de alta películas**, con formulario validado, almacenamiento persistente mediante `localStorage` y visualización en tarjetas responsivas.

🔗 **[Ver demo (deploy)](https://altasdepeliculashd.netlify.app/)** 

---

## ✨ Características

- ✅ Formulario con validación completa (React Hook Form)
- ✅ Mensajes de error en tiempo real
- ✅ Almacenamiento persistente con `localStorage`
- ✅ Visualización de películas en tarjetas responsivas
- ✅ Eliminar películas con confirmación implícita
- ✅ Diseño oscuro moderno con efecto *glassmorphism*
- ✅ Totalmente responsivo (móvil, tablet, escritorio)
- ✅ Integración con `react-bootstrap` para componentes
